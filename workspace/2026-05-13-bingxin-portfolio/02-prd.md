## TL;DR
这是一个面向产品设计师 / UX 设计师 / 产品经理岗位的双语响应式作品集网站，用 Design Journey 插画首页快速展示项目价值、AI 设计能力与个人气质。

## 1. 产品定位
- **是什么**：Bingxin Du 的个人作品集网站。
- **给谁用**：招聘方、设计负责人、产品负责人、HR、潜在合作方。
- **解决什么问题**：让访客快速理解 Bingxin 的项目经验、角色贡献、C 端设计能力、AI 产品与流程设计能力。
- **衡量成功**：有效联系 / 面试邀约；Featured 项目点击率；简历下载率；移动端停留时长。

## 2. 范围
### 本期做
- 首页 Hero：使用 Design Journey 插画效果图作为视觉基准。
- 8 个项目展示：默认显示 Role / Value。
- 3 个主推项目：HuKe / Zencard / SRE Agent。
- AI Design Flow。
- About / Timeline / Contact。
- CN / EN 双语切换。
- 桌面与手机端适配。
- 首页动效：项目浮动、路径光点、定位点脉冲、小熊猫轻动效。

### 本期不做
- 后台 CMS。
- 完整博客系统。
- 登录系统。
- 复杂 3D。
- 全量真实项目内容，先 mock。

### 3.2 功能详述
#### F1 Design Journey 首页
- **目标**：建立强记忆点，同时表达专业身份。
- **验收点**：
  - [ ] 首屏展示 Bingxin Du。
  - [ ] 明确 Product Designer / UX Designer / Product Manager。
  - [ ] 有 Explore Work CTA。
  - [ ] 小熊猫阅读形象可见。
  - [ ] 3 个主推项目在首屏可见。

#### F2 项目快速识别
- **目标**：减少招聘方点击成本。
- **验收点**：
  - [ ] 每个项目卡默认显示项目名、Role、Value。
  - [ ] 手机端也能看到关键信息。
  - [ ] Featured 项目权重高于普通项目。

#### F4 AI Design Flow
- **目标**：突出全栈 AI 设计特色。
- **验收点**：
  - [ ] 展示 Problem → Research → AI Workflow → Prototype → Evaluate。
  - [ ] SRE Agent 与 AI Flow 强关联。
  - [ ] 文案避免空泛 AI 标签。

## 4. 非功能需求
- **性能**：Hero 图片需压缩，首屏尽量小于 2.5s。
- **兼容性**：Chrome / Safari / Edge；桌面与手机。
- **安全**：公司项目需脱敏。
- **可访问性**：按钮和热区可聚焦；支持 reduced motion；图片提供语义替代。
- **可维护性**：下一阶段应将整图切分为背景、小熊猫、卡片、文字 HTML。

## 5. 优先级说明
P0 是首页、项目快速识别、Featured 项目、AI Flow、双语、响应式和联系入口，因为它们直接影响作品集是否能被看懂和转化。P1 是 About、Timeline 与更细的个人叙事。
